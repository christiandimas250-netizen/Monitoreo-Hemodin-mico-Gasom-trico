# Monitoreo-Hemodin-mico-Gasom-trico
Monitor Hemodinámico Gasométrico es una aplicación web para el análisis integrado de variables hemodinámicas y de transporte de oxígeno derivadas de gasometría arterial y venosa. Calcula e interpreta parámetros clave para la evaluación de perfusión tisular, aporte y consumo de oxígeno en el entorno perioperatorio y de cuidados críticos.
